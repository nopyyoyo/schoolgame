Final Fantasy VI - Spell Effects 1 - Curated Reconstruction v3

Folders: Fire, Ice, Bolt, Fire2, Ice2, Poison, Drain, Bolt2, Bio, Fire3, Ice3, Bolt3, Break.
Each folder contains sequential Frame_01.png files and one animated GIF.
The supplied sheet uses several layouts: individual grid cells, horizontal progressions, multiple rows, and component phases. Frames were therefore cropped and ordered per labeled effect rather than by one global grid.
All frames within an effect are centered on a consistent transparent canvas to reduce GIF jitter. Black guide borders and blue label buttons are excluded.
